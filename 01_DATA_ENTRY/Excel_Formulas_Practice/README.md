# Excel Formulas Practice

## Project Overview
This project demonstrates practical Excel formulas and basic data analysis using a student marks dataset.

## Dataset
The dataset contains 50 student records with:
- Student ID
- Student Name
- Subject
- Marks
- Result

## Tasks Performed
- Used IF formula to calculate Pass/Fail
- Used COUNTIF to count passed and failed students
- Used SUM to calculate total marks
- Used AVERAGE to calculate average marks
- Used MAX to find the highest marks
- Used MIN to find the lowest marks
- Sorted students by marks
- Filtered students based on results
- Used Conditional Formatting to highlight marks below 40

## Results
- Total Students: 50
- Passed Students: 41
- Failed Students: 9
- Average Marks: 62.58
- Total Marks: 3,129
- Highest Marks: 96
- Lowest Marks: 25

- Microsoft Excel

## Skills Demonstrated
- Excel formulas
- Data analysis
- Sorting and filtering
- Conditional formatting
- Basic reporting
