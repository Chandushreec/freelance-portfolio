# E-Commerce Sales & Customer Analysis

## Project Overview

This project analyzes e-commerce sales and customer data using MySQL.

The database contains customers, products, orders, and order details. SQL queries were used to analyze sales performance, customer spending, product performance, order status, and monthly sales trends.

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- GitHub

## Database Structure

The project contains four tables:

- `customers` – Customer information
- `products` – Product details and prices
- `orders` – Order dates and order status
- `order_details` – Products and quantities included in each order
