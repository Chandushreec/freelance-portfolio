# Expense Data Analysis

## Project Overview

This project demonstrates the use of Microsoft Excel to organize, analyze, and summarize business expense data.

## Dataset

The dataset contains 30 expense records with the following columns:

- Expense ID
- Category
- Description
- Amount
- Payment Method
- Month

## Tasks Completed

- Organized expense records in Excel
- Formatted the Amount column as currency
- Used SUM to calculate total expenses
- Used COUNTA to count expense records
- Used AVERAGE to calculate average expense
- Used MAX to find the highest expense
- Used MIN to find the lowest expense
- Sorted expenses from largest to smallest
- Applied filters to analyze expense categories

## Results

- Total Expenses: ₹52,850
- Number of Expenses: 30
- Average Expense: ₹1,761.67
- Highest Expense: ₹4,500
- Lowest Expense: ₹450
