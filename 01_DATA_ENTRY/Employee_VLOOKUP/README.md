# Employee VLOOKUP

## Project Overview

This project demonstrates the use of Microsoft Excel VLOOKUP to retrieve employee information from a master employee table.

## Workbook Structure

### Employee Master
Contains the complete employee database with:

- Employee ID
- Employee Name
- Department
- Salary

### Salary Lookup
Uses Employee IDs to automatically retrieve:

- Employee Name
- Department
- Salary

## Tasks Completed

- Created an Employee Master table
- Created a Salary Lookup table
- Used VLOOKUP to retrieve employee names
- Used VLOOKUP to retrieve departments
- Used VLOOKUP to retrieve salaries
- Used SUM to calculate total salary
- Used AVERAGE to calculate average salary
- Used MAX to find the highest salary
- Used MIN to find the lowest salary
- Applied currency formatting

## Results

- Employees in lookup table: 10
- Total Salary: ₹3,95,000
- Average Salary: ₹39,500
- Highest Salary: ₹48,000
- Lowest Salary: ₹32,000
