# Sales Data Analysis

## Project Overview
This project demonstrates basic sales data analysis using Microsoft Excel.

## Tasks Performed
- Organized sales data
- Calculated Total Sales using Quantity × Price
- Sorted sales from highest to lowest
- Filtered sales by city
- Calculated total sales
- Calculated average sale value
- Counted the total number of orders

## Dataset
The dataset contains:
- Order ID
- Product
- Category
- Quantity
- Price
- Salesperson
- City
- Total Sales

## Results
- Total Sales: ₹294,500
- Average Sale: ₹19,633.33
- Number of Orders: 15
