# Employee Leave Tracker

## Project Overview

This project demonstrates the use of Microsoft Excel for managing employee leave records, using data validation, filtering, and basic formulas.

## Dataset

The dataset contains 30 employee leave records with the following columns:

- Employee ID
- Employee Name
- Department
- Leave Type
- Leave Days
- Status

## Tasks Completed

- Created an employee leave tracking sheet
- Added Data Validation dropdowns for Leave Type
- Added Data Validation dropdowns for Status
- Used SUM to calculate total leave days
- Used COUNTIF to count Approved, Pending, and Rejected requests
- Applied Excel filters to analyze leave records

## Results

- Total Employees: 30
- Total Leave Days: 78
- Approved Requests: 17
- Pending Requests: 8
- Rejected Requests: 5
