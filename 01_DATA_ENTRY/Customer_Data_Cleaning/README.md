# Customer Data Cleaning & Organization

## Project Overview
This project demonstrates how I cleaned and organized customer data using Microsoft Excel.

## Tasks Performed
- Removed duplicate customer records
- Standardized customer names
- Standardized city names
- Identified and handled missing email data
- Formatted phone numbers
- Formatted purchase amounts
- Created a summary of the cleaned data

## Dataset
The dataset contains customer information including:
- Customer ID
- Name
- Email
- Phone Number
- City
- Age
- Purchase Amount

## Results
- Total Customers: 27
- Total Purchase Amount: ₹65,980
- Average Purchase Amount: ₹2,443.70

## Tools Used
- Microsoft Excel
